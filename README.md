int number = 256; Байты: 00-01-00-00

int number = 65536; Байты: 00-00-01-00
1) В C# тип int — это 32-битное целое число
2) Один байт может вместить максимум 256 комбинаций (числа от 0 до 255). После этого начинает использоваться 2-й байт
3) Число 65536 переходит границу уже первых двух байтов и задействует третий байт.
