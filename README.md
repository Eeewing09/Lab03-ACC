# Практическая работа №3
## Цель
## 1. Представление числа в байтах
Для выбранных значений:
- 01-00-00-00
- 00-01-00-00
- 00-00-01-00
Один байт может вместить максимум 256 комбинаций (числа от 0 до 255). После этого начинает использоваться 2-й байт
## 2. Порядок байтов
- True;
- число `305419896`;
- 0x12345678;
- 78-56-34-12;
- Порядок байтов на современных х86-64 системах рабоатат по принципу Little-endian
## 3. Текст и UTF-8
Сравнение:
- `ABC`;
- `Привет`.
Строка: ABC, Количество символов: 3, Количество байтов: 3; Строка: Привет, Количество символов: 6, Количество байтов: 12
В кодировке UTF-8 размер одного символа в байтах зависит от языковой группы, к которой он принадлежит
## 4. Английская и русская буква
Сравнить:
- `A`;
- `А`.
Латинская A занимает 1 байт (41), а русская A — 2 байта (D0-90).
Разница в том, что это буквы из разных алфавитов. UTF-8 кодирует базовую латиницу экономно (в 1 байт), а для кириллицы использует увеличенный размер (2 байта)
## 5. Обратное преобразование
- Строка: Переводится в байты методом Encoding.UTF8.GetBytes(), а восстанавливается обратно без потерь через Encoding.UTF8.GetString().
- Число: Разбивается на массив байтов с помощью BitConverter.GetBytes(), а собирается обратно в исходное значение через BitConverter.ToInt32()
## Контрольные вопросы
1. Байт и биты: Байт — единица данных; содержит 8 бит.
2. Почему int 4 байта: Чтобы вмещать большие числа (до ±2 млрд).
3. BitConverter.GetBytes(): Разбивает число на массив составляющих его байтов.
4. BitConverter.IsLittleEndian: Показывает, хранятся ли младшие байты первыми (True — да).
5. Порядок байтов: Процессору (x86/x64) быстрее считать числа с младших разрядов (справа налево).
6. Символы и байты: В UTF-8 латиница весит 1 байт, кириллица — 2 байта, эмодзи — 4 байта.
7. Encoding.UTF8.GetBytes(): Переводит текст в байты по стандарту UTF-8.
8. Encoding.UTF8.GetString(): Расшифровывает сырые байты обратно в текст.
9. Разная интерпретация: Байты — просто цифры. Без указания типа (текст, число, фото) компьютер их не поймет.
10.Число кодируется в байты целиком (как величина), а текст — посимвольно (буква за буквой).
## Итоговый вывод
Данные в памяти — это просто байты. Компьютер не различает текст и числа сами по себе.Числа кодируются целиком как единое математическое значение. Современные процессоры (x86/x64) хранят их в порядке Little-endian.Текст кодируется посимвольно. В международном стандарте UTF-8 размер символа динамический: английские буквы занимают 1 байт, русские — 2 байта
